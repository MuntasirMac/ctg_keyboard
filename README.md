# Chittagonian Keyboard

A specialized native mobile keyboard layout built for typing the Chittagonian language with precise pitch accents and custom phonetic symbols.

## 🚀 Easy Installation Guide

1. Download and install the official free **Keyman App** for your device:
   * [Get it on Android (Google Play)](https://play.google.com/store/apps/details?id=com.tavultesoft.kmapro)
   * [Get it on iOS (App Store)](https://apps.apple.com/app/keyman/id917902928)

2. Once the Keyman app is installed, tap the button below on your mobile device to download and activate the Chittagonian layout:

[![Install Keyboard](https://img.shields.io/badge/Install%20Chittagonian%20Keyboard-1976D2?style=for-the-badge&logo=keyman)](https://github.com/MuntasirMac/ctg_keyboard/raw/main/keyboards/chittagonian/chittagonian.kmp)

Alternatively, open this link in your mobile browser:
```
https://github.com/MuntasirMac/ctg_keyboard/raw/main/keyboards/chittagonian/chittagonian.kmp
```
