# Chittagonian Tonal Keyboard 

A specialized native mobile keyboard layout built for typing the Chittagonian language with precise pitch accents and custom phonetic symbols.

## 🚀 Easy Installation Guide

1. Download and install the official free **Keyman App** for your device:
   * [Get it on Android (Google Play)](https://google.com)
   * [Get it on iOS (App Store)](https://apple.com)

2. Once the Keyman app is installed, tap the deployment button below on your mobile device to automatically download and activate the Chittagonian Tonal layout:

[![Install Keyboard](https://shields.io)](keyman://download/keyboard/chittagonian?source=https://githubusercontent.com[YOUR_GITHUB_USERNAME]/[YOUR_REPO_NAME]/main/chittagonian.kmp)
